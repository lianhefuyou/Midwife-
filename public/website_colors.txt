台北市立聯合醫院 婦幼院區「溫柔生產」衛教網站 ─ 完整色彩配置表（Color Palette）

本網站採用溫和、溫馨且具親和力的「自然暖沙與蜜桃粉 (Natural Tones & Peach)」色彩計畫，旨在為孕產婦及其家庭營造安全、溫柔、舒適且具專業感的視覺氛圍。

======================================================================
1. 主視覺與背景色 (Brand & Background Colors)
======================================================================
■ 蜜桃粉 / 溫柔粉 (Peach / Soft Coral Pink)
  - 色碼：#FBC4AB
  - 用途：主色調、主選單啟用狀態背景、漸層起始色、重要按鈕與裝飾。
  - 感受：溫柔、母愛、和諧、溫暖。

■ 暖沙黃 / 暖陽黃 (Warm Sand / Gentle Apricot)
  - 色碼：#f7ddb5 (或 #F7DDB5)
  - 用途：網頁底色漸層結束色、卡片與標章背景、溫和界限。
  - 感受：自然、安心、堅實的陪伴。

■ 淺蜜桃 / 柔粉白 (Very Light Peach / Pinkish White)
  - 色碼：#FFF0E8
  - 用途：輕盈區塊背景、按鈕或卡片的微光效果。

■ 奶油白 / 溫潤白 (Creamy White / Warm Butter)
  - 色碼：#FFF8EE
  - 用途：影音區塊背景、細緻對比。

■ 暖白 / 柔白 (Warm Cream / Soft Alabaster)
  - 色碼：#fdfaf7 與 #fffaf0
  - 用途：互動問答（QA）卡片背景、柔和卡片填充。

■ 純白 (Pure White)
  - 色碼：#ffffff
  - 用途：卡片主背景、外框白邊（提升層次與立體感）。

======================================================================
2. 文字與輔助色 (Typography & Secondary Colors)
======================================================================
■ 暖深褐 / 深灰褐 (Warm Dark Brown / Dark Espresso)
  - 色碼：#4A3E3D
  - 用途：網頁主要內文字（取代死黑，降低眼部疲勞）、主要標題文字、啟用選單字體。
  - 感受：沉穩、專業、柔和而不失莊重。

■ 煙燻灰 / 灰褐色 (Smoked Gray / Taupe Gray)
  - 色碼：#7D6F6D
  - 用途：次要說明文字、輔助標籤、未選中狀態的文字與圖示。

======================================================================
3. 強調與功能色 (Accents & Functional Colors)
======================================================================
■ 焦糖暖橘 / 主題亮橘 (Caramel Orange / Burnt Orange)
  - 色碼：#c96d42 (或 #C96D42)
  - 用途：重點強調、關鍵指引按鈕、進度條填滿色、浮動引導按鈕。
  - 感受：活潑、清晰、指引方向。

■ 深焦糖色 (Deep Caramel)
  - 色碼：#b05a30
  - 用途：焦糖暖橘按鈕與元素之 Hover（懸停）狀態。

■ 典雅金 / 琥珀棕 (Elegant Gold / Amber Brown)
  - 色碼：#b38a57 (或 #B38A57)
  - 用途：卡片精緻邊框、特色標籤文字、細緻的裝飾線與圖示色。
  - 感受：專業、精緻、值得信賴。

■ 柔和金 / 香檳金 (Soft Gold / Champagne Gold)
  - 色碼：#D4B98E
  - 用途：金色系輔助色、卡片 Hover 微光。

■ 翡翠綠 / 成功綠 (Emerald Green)
  - 色碼：#2a9d8f (與 #10b981 / #34d399)
  - 用途：互動問答「正確選項」與「O」之醒目標示。

■ 珊瑚紅 / 錯誤紅 (Coral Red / Error Red)
  - 色碼：#e76f51 (與 #f43f5e / #f87171)
  - 用途：互動問答「錯誤選項」與「X」之醒目標示。

======================================================================
4. CSS 變數對照表 (CSS Variables Reference)
======================================================================
在專案中的 styles/theme.module.css 定義之變數：

:root {
  --color-primary: #FBC4AB;
  --color-primary-light: #FFF0E8;
  --color-secondary: #f7ddb5;
  --color-secondary-light: #FFF8EE;
  --color-accent: #b38a57;
  --color-accent-light: #D4B98E;
  --color-dark: #4A3E3D;
  --color-bg-soft: #f7ddb5;
  --color-bg-pure: #ffffff;
  --color-gray: #7D6F6D;
}
